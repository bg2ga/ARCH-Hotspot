# Third-party components and licenses

This repository contains scripts, configuration and prebuilt ARM binaries used with several upstream open-source radio projects. Copyright remains with the upstream authors.

## Main components

- MMDVM-Host
- MMDVM-IQ
- MMDVM-Multi
- DMRGateway
- YSFGateway / YSFClients
- P25Gateway / P25Clients
- NXDNGateway / NXDNClients
- ircDDBGateway
- SoapySX / sxxcvr
- liquid-dsp
- Mosquitto, nginx and other Debian runtime dependencies

The upstream source bundle and build procedure are referenced by `build_upstream.sh`. Each component remains subject to its own upstream license and copyright notices.
